## Executive Overview

Forward Deployed Engineering is one of the most demanding and lucrative hybrid engineering specializations in the technology sector today. Popularized by Palantir Technologies and expanded across leading AI/LLM labs (OpenAI, Anthropic, Scale AI), autonomous defense contractors (Anduril), cloud hyperscalers (AWS, Azure, GCP), and enterprise fintechs (Ramp, Databricks), FDEs sit squarely at the intersection of **deep technical delivery** and **mission-critical client engagement**.

**Vanguard FDE** is engineered to provide an interactive, zero-external-dependency learning platform running completely offline or inside air-gapped environments. It combines theoretical mastery, code-level lab challenges, realistic stakeholder conflict simulations, real-world field missions with branching decision gates, an interactive bash bastion terminal, and an automated take-home code challenge evaluator.

---

## What is a Forward Deployed Engineer (FDE)?

Unlike a standard Software Engineer (SWE) who works internally against product roadmaps, or a Solutions Architect (SA) who focuses primarily on pre-sales diagrams and high-level architectural proposals, a **Forward Deployed Engineer**:
- **Deploys directly into customer territory**: Often embedded on-site in enterprise data centers, corporate headquarters, or defense SCIFs (Sensitive Compartmented Information Facilities).
- **Writes production-grade software**: Builds bespoke connectors, distributed streaming pipelines, custom ontology schemas, and client-specific integrations that directly extend the core platform.
- **Navigates enterprise bureaucracy & friction**: Resolves resistance from entrenched database administrators, strict corporate CISOs, network gatekeepers, and impatient C-suite sponsors.
- **Maintains extreme security compliance**: Implements mTLS, air-gapped zero-trust deployments, Federal Information Processing Standards (FIPS), DoD Impact Levels (IL5/IL6), PCI-DSS, and HIPAA protocols without external internet access.

    2. `drill mtls`: Verify TLS certificates and expiration dates with `openssl s_client`.
    3. `drill egress`: Test air-gap network isolation and egress firewall rules.
    4. `drill docker`: Inspect container health status and restart policies.
    5. `drill psql`: Query PostgreSQL connection pooling and active transactions.
    6. `drill jq`: Parse and format raw streaming JSON payloads.
    7. `drill netstat`: Inspect listening system ports and socket states.
    8. `drill hash`: Verify file integrity and cryptographic checksums using `sha256sum`.
    9. `drill logs`: Tail live Docker container logs with error filtering.
    10. `drill route`: Inspect default kernel routing tables and gateways.
    11. `drill df`: Monitor disk usage on mounted root and storage partitions.
    12. `drill top`: Monitor high-CPU processes and thread saturation.
  - Interactive auto-suggest buttons and command execution history.
- **Personalized Notes & Snippets Manager**:
  - Create, edit, and search local study notes.
  - Organize by tags (`Architecture`, `Interview`, `Security`, `AirGap`, etc.).

## Installation & Local Setup

### Prerequisites
- **Node.js**: Version 18.0.0 or higher (v20+ or v22+ recommended)
- **npm**: Version 9.0.0 or higher

### 1. Clone the Repository
```bash
git clone https://github.com/your-org/vanguard-fde.git
cd vanguard-fde
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start the Development Server
```bash
npm run dev
```
The application will be available at `http://localhost:3000`. In development mode, `server.ts` boots an Express server with Vite middleware dynamically mounted.

### 4. Build for Production
```bash
npm run build
```
Generates optimized static assets in the `/dist` directory.

### 5. Run Production Server
```bash
npm start
```
Starts the production Express server serving the compiled frontend application.

## Data Persistence & Air-Gap Offline Architecture

Vanguard FDE is explicitly architected to function inside zero-connectivity environments (such as DoD SCIFs or isolated enterprise VLANs):
1. **Zero External Calls**: All fonts use native system typefaces (`system-ui`, `-apple-system`, `Segoe UI`, `Roboto`). All icons are vector SVGs hardcoded directly into the template literals in `app.js`.
2. **Local Storage Persistence**:
   - `fde_notes`: User-created study notes with timestamps and tags.
   - `fde_snippets`: Saved code snippets and shell commands.
   - `fde_progress`: Module completion IDs, bookmark IDs, flashcard mastery scores, and take-home challenge states.
   - `fde_dod_checks`: Persistent boolean map of Definition of Done checklist verifications.
3. **PWA Service Worker**: When accessed over HTTPS or `localhost`, `public/sw.js` automatically precaches the core application assets (`/`, `/index.html`, `/app.js`, `/main.css`, `/public/catalog.json`), enabling instant loading even if the network adapter is physically disconnected.
