## 1. Getting Started & Interface Overview

### Top Navigation Bar
When you open Vanguard FDE, the clean top navigation bar provides instant access to the five core operational domains of the platform:

```
[VANGUARD FDE LOGO]  [Careers & Overview]  [Learning Skills]  [Interview Prep]  [Job Hunting]  [Accelerator]  [Progress Stats]
```

- **Brand Indicator**: Clicking the top-left logo immediately returns you to the home overview.
- **Primary Section Tabs**:
  1. **FDE Careers & Overview**: The high-level foundation detailing the day-in-the-life, archetypes, role comparison matrix, stakeholder conflict simulator, and compliance matrix.
  2. **Learning Skills**: The full technical curriculum covering 8 core engineering disciplines, code examples, hands-on labs, and official training resources.
  3. **Interview Prep**: The testing grounds featuring technical/behavioral interview questions, system architecture whiteboard templates, 3D flashcards, the 3-hour Take-Home code sandbox, and branching Field Missions.
  4. **Job Hunting**: Tactical career guides, resume frameworks, sourcing queries, company dossiers (Palantir, Anduril, Scale AI, etc.), and cold outreach generators.
  5. **Accelerator**: Field productivity tools, including the 12-drill Bastion Terminal emulator, local notes vault, code snippet manager, cheat-sheets, and 1-click Markdown export.
- **Progress Counter**: Located on the right of the navigation bar, displaying your overall curriculum completion percentage (e.g., `Progress: 38% (3/8 Modules)`).

### Keyboard Navigation & Shortcuts
- `Tab` / `Shift+Tab`: Cleanly navigates through interactive buttons, inputs, and cards.
- `Escape`: Closes any open modal (Module Deep Dive, Dataset Inspector, or Mission Telemetry) without submitting or resetting state.
- `Up` / `Down` (in Terminal): Cycles through your bash command history in the Bastion Field Terminal.

### Offline Mode & PWA Installation
Vanguard FDE is built as a Progressive Web App (PWA):
1. **Air-Gap Capability**: Vanguard makes **zero calls** to third-party CDNs, external font repositories, or tracking services.
2. **Installation**: In Chromium browsers (Chrome, Edge, Brave), click the **Install App** icon in the address bar to install Vanguard FDE as a standalone desktop application.
3. **Data Security**: All your notes, snippets, challenge code, and progress remain 100% stored inside your local browser storage (`localStorage`). No private notes are ever transmitted to an external cloud server.

### Interactive Bastion Field Terminal Simulator
A functional command-line emulator simulating an SSH session into a remote client bastion host (`bastion.client-corp.internal`):
- **Command Input**: Type commands directly into the terminal prompt.
- **Auto-Suggest Buttons**: Click any of the quick-action drill chips below the terminal to insert and run the command instantly.
- **Command History**: Use `Up` and `Down` arrow keys to cycle through past commands.

### The 12 Diagnostic Terminal Drills
| Command | What it Tests & Outputs |
|---|---|
| `drill network` | Tests TCP port connectivity to `10.240.0.12:5432` with `nc -zv`. Identifies closed firewall ports. |
| `drill mtls` | Inspects remote TLS certificate chains, expiry dates, and subject names using `openssl s_client`. |
| `drill egress` | Emulates DNS egress probes and firewall dropped packet logs in an air-gapped subnet. |
| `drill docker` | Checks container health status, uptime, and restart loop policies with `docker ps -a`. |
| `drill psql` | Inspects PostgreSQL active connections, long-running queries, and connection pool saturation. |
| `drill jq` | Demonstrates parsing and transforming complex JSON event streams into structured tabular data. |
| `drill netstat` | Lists all active listening TCP/UDP sockets, interfaces, and process IDs with `netstat -tuln`. |
| `drill hash` | Computes and verifies cryptographic SHA-256 checksums on deployment tarballs. |
| `drill logs` | Tails live Docker container logs (`fde-gateway`) with error filtering. |
| `drill route` | Inspects the host kernel routing table, network interfaces, and default gateways. |
| `drill df` | Checks disk usage, inode capacity, and mounted volumes on root and storage partitions. |
| `drill top` | Identifies high-CPU processes, memory leaks, and thread saturation. |

## 8. Frequently Asked Questions (FAQ) & Troubleshooting

**Q: Where is my data stored? Will I lose my notes if I close the browser?**  
A: All data is saved directly in your browser's `localStorage`. You can close the tab, refresh the page, or restart your computer, and all your notes, snippets, checklist items, and test results will remain intact.

**Q: Can I use this app on an air-gapped machine with no internet connection?**  
A: Yes! Vanguard FDE is 100% air-gap capable. Once cached by the Service Worker or run via `npm run dev` on localhost, the app makes zero external network calls.

**Q: How do I reset my progress if I want to restart the curriculum?**  
A: Open your browser's Developer Tools (`F12`), go to the **Application** or **Storage** tab, select **Local Storage**, and click **Clear All**. Then refresh the page.

**Q: What should I do if the Take-Home challenge test runner shows an error?**  
A: Check the terminal log at the bottom of the Take-Home tab. The test runner checks that your function returns valid JSON objects with numerical USD amounts and handled null fields. If a JavaScript syntax error occurs, the runner captures the stack trace and displays it in red.

**Q: Can I customize the curriculum or add new modules?**  
A: Yes. You can add new modules to `public/catalog.json`. Follow the JSON schema documented in `ARCHITECTURE.md`, and the client will automatically render your new modules in the curriculum grid.
